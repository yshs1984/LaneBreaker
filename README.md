# Lane Breaker

スマホのブラウザで完結して遊べる、5レーン制の連射シューティングゲームです。

## 遊び方

1. `index.html` をブラウザで開き、「スタート」ボタンで開始します
2. 画面はスマホ縦持ち想定。ドラッグ（PCではマウスドラッグ）または矢印キー（←→）で自機を最寄りのレーンへ移動します。自機は自動連射します
3. 画面は5レーンに分かれています。敵専用レーン（0, 2, 4番目、赤み背景）と、供給専用レーン（1, 3番目、水色み背景）に役割が固定されています
4. 敵は自分のレーンに沿って直進してきます。画面下端に到達すると、レーンに関係なく必ず被弾します
5. 供給レーンには一定間隔でアイテムが降ってきますが、触れるだけでは取れません。弾を当てて氷を割り、割れた後に触れて初めて回収できます。連射（速）・弾数（散）・攻撃力（撃）は永続的にレベルアップしますが、一定時間ごとに1段階ずつ下がっていくため、取り続ける必要があります。「散」はレベルが上がるほど弾が1発→3発→5発（すべて直線）に増え、連射間隔も短くなります
6. シールド（盾）は被弾を1回無効化するストック式、回復（回）は即座にHPを回復します
7. ウェーブが進むと「装甲」「エリート」「タイタン」と段階的に強い敵が出現します。エリート以上は光って予告した後に自機のレーンへ狙いを切り替えてくるため、同じ場所に留まり続けるのは危険です
8. 5ウェーブごとに大型のボス、または密集編隊のコンボイが出現します。登場中は道中の雑魚が止まり、撃破すると通常の進行に戻ります。ボスは居座ったレーンへ定期的に一撃を放ってくるので、狙われているレーンには留まらないようにしましょう。ボス撃破ではアイテムが確定でドロップします
9. HPが0になるとゲームオーバー。到達ウェーブに応じたランク（S〜D）とスコアが表示されます

## 構成

- `index.html` — キャンバスとHUD、スタート/ゲームオーバー画面
- `version.js` — バージョン番号（自動生成、手動編集しない）
- `game.js` — ゲームロジック一式（レーン管理・敵の出現とAI・パワーアップ・描画・ループ）
- `tools/` — 開発用の検証ハーネス（`node tools/verify.mjs`）

ビルド不要。`index.html` を開くだけで動作します。
